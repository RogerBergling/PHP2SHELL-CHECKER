Om PHP2Shell och hur kontrollen fungerar

Vad kontrolleras?

Skannern letar efter PHP-indikatorer i HTTP-huvuden, cookies, HTML-länkar, felmeddelanden och kända PHP-applikationer. Om en version hittas jämförs den med de rättade PHP-versionerna.

Rättade versioner

  • PHP 8.5.12 eller senare
  • PHP 8.4.27 eller senare
  • PHP 8.3.36 eller senare
  • PHP 8.2.35 eller senare
  • PHP 8.1 och äldre: EOL – backport krävs

Begränsningar

En sajt kan vara PHP-baserad utan att avslöja versionen. PHP – okänd version betyder att du måste kontrollera servern manuellt. CDN, WAF och anpassade fel sidor kan dölja svaren.
